## 3.0.0

- Rewritten from scratch, now available for Fabric as well as NeoForge
- Now available for Minecraft 26.1.2 as well as 1.21.1
- Existing 1.21.1 worlds carry over, including the contents of placed hoppers and floppers
- Added Copper Hoppers, which oxidize over time and slow down at each stage. Wax them with honeycomb to stop aging, scrape them with an axe
- Added the Stack Hopper, which moves a whole stack at a time
- Added the Void Hopper, which destroys items, with a filter for what gets destroyed
- Added the Splitter Hopper, which hands items out to every side in turn
- Added the Vacuum Hopper, which pulls in dropped items within an adjustable range
- Added the Pulse Hopper, which sends a set number of items on each redstone pulse
- Added the Upward Hopper, which moves items upwards
- Added the Linked Hopper and the Hopper Linker, for sending items wirelessly between two hoppers
- Added the XP Hopper, which collects and stores experience
- Added Iron, Golden and Diamond Floppers, with more capacity and speed
- Added the Filtered Flopper, which only accepts one fluid
- Added the Placing Flopper, which places its fluid into the world
- Filtered Hopper: added a blacklist mode, item tag matching and exact component matching
- Added config options for every new hopper and flopper
- Fixed the Flopper showing a missing model when facing east
